Assignment Scope
  • Subject Only: Teacher + Subject.
  • Program All: Program + all program subjects.
  • Class All: Class + its program subjects.
  • Program + Subject: Program + selected subjects.
  • Class + Subject: Class + selected subjects.
  • Program + Class + Subject: Program + class + subject.
  • Full: Program + class + section + subject.
Section Assignment
  • Sections belong to a class.
  • Select one or more sections.
  • Sections are filtered by selected classes.
  • Full Assignment uses sections together with program, class and subject.
