How bulk creation works
The system creates one ExamSubject for every valid Subject × Class combination. Only subjects with exactly one active teacher assignment are submitted. Subjects without a teacher are skipped. Subjects with multiple active teachers are also skipped so the system never guesses a teacher.

Section is optional. Bulk creation uses section_id = NULL, meaning the ExamSubject applies to the whole selected class.
Only active TeacherSubject assignments are used.

Important

Teacher Assignment
A subject with exactly one active TeacherSubject assignment will be created. Subjects without a teacher are skipped, not used as a reason to cancel the entire submission.
Multiple Teachers
If a subject has multiple active teachers, the system does not guess which teacher should be used. That subject is skipped.
Section
Section is optional. Bulk creation uses section_id = NULL, meaning the ExamSubject applies to the whole class.
Duplicate Protection
